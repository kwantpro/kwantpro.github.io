# Compaginis – Standalone Sports Analytics & Coaching Software
 
Oficjalna strona internetowa oprogramowania dla ekosystemu **Compaginis** – obejmującego system numerycznej predykcji sportowej **Predict** oraz profesjonalny system wsparcia sztabu szkoleniowego **Coach**.
 
## O Projekcie
Compaginis to dedykowane aplikacje desktopowe przeznaczone do analityki, modelowania statystycznego oraz kompleksowego wsparcia pracy sztabu szkoleniowego.
 
- **Oficjalna strona:** [compaginis.pl](https://compaginis.pl)
- **Produkty w ekosystemie:** 
  - **Compaginis Predict:** Analityka i predykcja numeryczna dla 7 dyscyplin sportowych.
  - **Compaginis Coach :** System wsparcia sztabu (zarządzanie kadrą, tablice taktyczne, obciążenia RPE & Wellness, macierz szatni, model zintegrowanej prognozy meczowej i generowania wyjściowej jedenastki).
- **Model dystrybucji:** Licencje czasowe na 1 stanowisko (przypisane do HWID).
- **Bezpieczeństwo i Autonomia:** Pełna prywatność – brak automatycznego pobierania danych z zewnętrznych API; aplikacje działają w pełni lokalnie na urządzeniu użytkownika.
 
## Stack Techniczny Strony
Strona docelowa (Landing Page) oraz dokumentacja zostały zbudowane przy użyciu:
- HTML5 / CSS3
- Tailwind CSS
- Lucide Icons
- GitHub Pages + Custom Domain (`compaginis.pl`)
