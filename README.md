# CompaginisPredict – Standalone Sports Analytics Software

Oficjalna strona internetowa oprogramowania **CompaginisPredict** – systemu do lokalnej analityki i modelowania statystycznego w sporcie.

## O Projekcie
CompaginisPredict to dedykowana aplikacja desktopowa przeznaczona do analizy danych sportowych.

- **Oficjalna strona:** [compaginis.pl](https://compaginis.pl)
- **Model dystrybucji:** Licencja czasowa (1, 3 lub 6 miesięcy)
- **Bezpieczeństwo:** Pełna prywatność – baza danych i obliczenia przetwarzane wyłącznie lokalnie na urządzeniu użytkownika.

## Stack Techniczny Strony
Strona docelowa (Landing Page) została zbudowana przy użyciu:
- HTML5 / CSS3
- Tailwind CSS
- Lucide Icons
- GitHub Pages + Custom Domain (`compaginis.pl`)
