# C​ompaginisPredict – Standalone Sports Analytics Software
 
Oficjalna strona internetowa oprogramowania
**C​ompaginisPredict** – systemu do lokalnej analityki i modelowania
statystycznego w sporcie.
 
## O Projekcie
C​ompaginisPredict to dedykowana aplikacja desktopowa
przeznaczona do analizy danych sportowych i prognozy wyników.
 
- **Oficjalna strona:**
[c​ompaginis.pl](https://compaginis.pl)
- **Model dystrybucji:** Licencja czasowa (1, 3 lub 6
miesięcy)
- **Bezpieczeństwo:** Pełna prywatność – baza danych i
obliczenia przetwarzane wyłącznie lokalnie na urządzeniu użytkownika.
