# Compaginis – Standalone Sports Analytics & Coaching Software

Oficjalna strona internetowa oprogramowania dla ekosystemu **Compaginis** – obejmującego system numerycznej predykcji sportowej **Predict**, profesjonalny system wsparcia sztabu szkoleniowego **Coach** oraz system prognozowania sportowego **Prognoser**.

## O Projekcie
Compaginis to dedykowane aplikacje desktopowe przeznaczone do analityki, modelowania statystycznego, kompleksowego wsparcia pracy sztabu szkoleniowego oraz prognozowania sportowego.

- **Oficjalna strona:** [compaginis.pl](https://compaginis.pl)
- **Produkty w ekosystemie:** 
  - **Compaginis Predict:** Analityka i predykcja numeryczna dla 7 dyscyplin sportowych.
  - **Compaginis Coach:** System wsparcia sztabu (zarządzanie kadrą, tablice taktyczne, obciążenia RPE & Wellness, macierz szatni, model zintegrowanej prognozy meczowej i generowania wyjściowej jedenastki).
  - **Compaginis Prognoser:** Narzędzie analityczno-prognostyczne oparte na autorskim, deterministycznym silniku lingwistyczno-probabilistycznym. Program analizuje publicznie dostępne dane informacyjne i formułuje słowny raport z prognozą procentową wyniku spotkania  - w całości na urządzeniu użytkownika.  W trakcie analizy wymagany jest ciągły dostęp do Internetu.
- **Model dystrybucji:** Licencje czasowe na 1 stanowisko (przypisane do HWID).
- **Bezpieczeństwo i Autonomia:** Pełna prywatność i praca na urządzeniu użytkownika. Programy Predict oraz Coach nie pobierają automatycznie danych z zewnętrznych API - użytkownik wprowadza dane samodzielnie lub za pomocą lokalnych baz/plików. Compaginis Prognoser korzysta w trakcie analizy z publicznie dostępnych danych informacyjnych, natomiast cała analiza, prognozowanie, lokalna baza i eksporty (PDF/TXT) wykonywane są wyłącznie lokalnie. Żaden z programów nie wykorzystuje sztucznej inteligencji (AI) ani sieci neuronowych.
